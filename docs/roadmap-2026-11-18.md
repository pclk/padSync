## Pencil writing on iPad (top priority)

0a. ~~**Pencil sometimes freezes and stops taking input**~~ ✅ done 2026-11-18 (01:45 run).
    Root causes found and fixed:
    - **Stuck gesture (main cause).** `InkController.down()` returned early while `this.gesture`
      was set, and `move`/`up` only listened to that gesture's `pointerId`. One lost
      `pointerup`/`pointercancel` (capture lost, Scribble, an edge swipe or app switch, a section
      unmounting mid-stroke) left the gesture open forever, so every later Pencil touch was
      ignored, and two-finger pinch was disabled too (`!controller.isDrawing()`). Now a new
      pointerdown commits the stale gesture and starts fresh; `lostpointercapture`, a hover move
      with `buttons === 0` from the drawing pointer, window `blur`/`pagehide`/hidden visibility
      and SectionView unmount all end it (keeping what was drawn). `setPointerCapture` throwing
      for a pointer WebKit already dropped no longer aborts the stroke.
    - **Pen vs. scrolling.** The pan claim is avoided by the existing non-passive window
      `touchstart`/`touchmove` `preventDefault` for stylus touches on `.ink-surface` (confirmed;
      `touch-action` stays `pan-x pan-y` so fingers still scroll). A pen touch that lands during
      momentum scrolling can still get a `pointercancel` from WebKit (that touchstart is not
      cancelable) — it now commits and frees the pen instead of wedging.
      `.ink-surface` also sets `-webkit-touch-callout: none` and `-webkit-user-drag: none`.
    - **Main-thread work during writing.** Each stroke commit did an IndexedDB write, a second
      write for `logEvent`, an `emitActivity` that re-renders the whole editor (layout mode), and
      sync could start encoding/applying mid-stroke. `logEvent` and `emitActivity` for strokes and
      erases now run in `requestIdleCallback` (50 ms timeout fallback on Safari); background sync
      waits (250 ms steps, at most 3 s) while a gesture is open (`isInking()` in
      `src/lib/activity.ts`). Not measured on a device in this run — check with the sync debug panel.
    Tests: `tests/pencil-freeze.test.ts`.
0b. **Pencil lines less smooth than the trackpad, and stray dots** — the mouse path uses simulated
    pressure, the pencil uses raw `pressure` with `thinning: 0.55` and `streamline: 0.32`
    (`src/ink/render.ts`), so pressure noise shows as wobbly width; the first pencil samples often
    have near-zero pressure; short taps or a resting/bouncing pencil commit as dots.
    **[scheduled 02:30]**

## Improvements

### UX and design
1. **Custom rename/delete dialogs with undo** — replace `window.prompt`/`confirm` in the library
   with in-app dialogs (focus trap, Esc, Enter) and an "Undo" toast after delete. **[scheduled 03:15]**
2. **Dark mode** — dark tokens for the chrome (paper stays light), following the system, with a
   Light/Dark/System choice in Settings. **[scheduled 04:00]**
3. **Clearer sync status** — SyncBadge states for offline, retrying (with countdown), failed
   (with a Retry button) and signed out; a short tooltip explaining each. **[scheduled 05:30]**
4. Toasts for background failures (PDF upload, AI import send) instead of inline text only.
5. Loading skeletons for the library and editor instead of blank space while IndexedDB opens.
6. Touch targets: audit every icon button for ≥44px on iPad; larger hit areas on the tool rail.
7. Accessibility pass: colour contrast of muted text, focus order in the side panel, live region
   for sync and upload progress.

### Quality and performance
8. **Real notebook previews** — render a small thumbnail of the first page (ink or PDF page 1) on
   library cards instead of the generic dot paper. **[scheduled 06:15]**
9. Bound sync batches by encoded bytes as well as entity count (docs/sync-timing.md, option 5).
10. Coordinate duplicate tabs with BroadcastChannel so only one tab polls (sync-timing option 4).
11. Server-side timing and byte instrumentation per sync operation (sync-timing option 1).
12. Lazy-load pdf.js and KaTeX so the library route ships less JavaScript.
13. Resolve the moderate `npm audit` findings noted in docs/polish-2026-11-17.md.
14. End-to-end smoke test (Playwright) for create → draw → reload → delete.
